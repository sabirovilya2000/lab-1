# Lab 1 — HTTP-клиент к SampleAPIs Coffee

Лабораторная работа №1: исследование публичного HTTP API и реализация Python-клиента на `requests` для каталога горячих напитков.

## Что делает программа

Скрипт `main.py` выполняет полный CRUD-сценарий из 8 шагов:

1. GET коллекции `/coffee/hot/` — список горячих напитков.
2. POST — создаёт новый напиток с уникальной меткой группы в названии.
3. GET /{id} — получает созданный напиток по id из ответа сервера, сверяет поля.
4. PUT /{id} — полностью заменяет данные, проверяет все заменённые поля.
5. PATCH /{id} — частично изменяет напиток (только description), проверяет, что остальные поля сохранились.
6. GET /{id} — подтверждает изменения.
7. DELETE /{id} — удаляет созданный напиток.
8. GET /{id} — получает ожидаемый 404 и корректно обрабатывает его.

В блоке `finally` программа гарантированно пытается удалить созданный ресурс, даже если сценарий упал в середине.

## Как запустить

```bash
pip install requests
python main.py
